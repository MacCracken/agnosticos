## Bug Reports & Feature Requests

- **Bug report**: [Open a GitHub Issue](https://github.com/MacCracken/agnosticos/issues/new?template=bug_report.md)
- **Feature request**: [Open a GitHub Issue](https://github.com/MacCracken/agnosticos/issues/new?template=feature_request.md)
- **General questions**: open an issue too — GitHub Discussions are not enabled on the repo

Before opening an issue, please:
1. Search [existing issues](https://github.com/MacCracken/agnosticos/issues) to avoid duplicates
2. Check the [troubleshooting guide](docs/installation/troubleshooting.md)
3. Gather relevant logs and system information

## Security Vulnerabilities

**Do NOT report security vulnerabilities in public GitHub Issues.**

Please follow the responsible disclosure process described in [SECURITY.md](SECURITY.md).
