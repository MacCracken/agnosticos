# AGNOS Binaries & Tools — Released (v1.0+)

> Standalone v1.0+ binaries and CLI tools in the AGNOS stack — the kernel, shell, init, package manager, build system, and the sovereign userland (coreutils, editors, viewers, terminal-aesthetics tools). Distinct from the reusable **[library crates](libs/README.md)** and from the larger **[consumer applications](README.md)** (Abacus, Aequi, …).
>
> Stdlib-folded distfiles (`sandhi`, `niyama`) are documented under [libs/ § Stdlib-Folded](libs/README.md).
>
> **Verify against each repo's `VERSION` before acting on a single row.** Cyrius pins are not carried in the rows — read the repo's `cyrius.cyml` (ecosystem summary in [state.md](../development/state.md)).
