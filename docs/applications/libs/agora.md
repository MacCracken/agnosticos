# agora

Telnet-served BBS — Sigil-backed Ed25519 auth, multi-board threaded boards, door games + Persistent-Universe shared-world multiplayer (Cyrius-native; binary).

- **Repository**: [github.com/MacCracken/agora](https://github.com/MacCracken/agora)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Greek ἀγορά — *civic marketplace / public assembly*. Two serve models, chosen by `AGORA_SERVE`: fork-per-accept or a single-process poll multiplex; full telnet RFC conformance. Its first three door games (Port Authority / Smuggler's Ledger / The Handler, with `flock`'d shared-world state) have since been joined by QUEST, a casino, a war-game, a code-breaking door, a chat area with four chatbots and a gateway into the Yeoman's Descent MUD. Anchors the BBS/MUD aesthetic cluster.

See the [libs registry](../README.md) for the full catalog and dependency context.
