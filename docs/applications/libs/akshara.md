# akshara

Sovereign tokenizer (अक्षर — *indivisible text/sound unit*) — the text→token-id layer of the ML family: an adaptive byte vocabulary, opt-in BPE (pure i64, bit-reproducible) and a width-generic packed token store; extracted from attn11 alongside rosnet and tyche.
