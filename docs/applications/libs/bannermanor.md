# bannermanor

figlet-equivalent ASCII-art banner generator (binary `bnrmr`).

- **Repository**: [github.com/MacCracken/bannermanor](https://github.com/MacCracken/bannermanor)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Login MOTDs / script intros / splash text. CYML font format (schema=1) + a default in-tree font set (block / slim / big) frozen as the v1.0 contract. English-wordplay naming lane (with commandress); `bnrmr` vowel-dropped.

See the [binaries registry](../binaries.md) for the full catalog and dependency context.
