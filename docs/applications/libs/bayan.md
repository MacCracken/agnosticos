# bayan

Data-format, document & big-integer distfile — json / yaml / toml / cyml / csv / base64 / pdf / bigint / u128 (Cyrius-native).

- **Repository**: [github.com/MacCracken/bayan](https://github.com/MacCracken/bayan)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Folded byte-identical into the Cyrius stdlib as `lib/bayan.cyr` per the sandhi pattern (since the cyrius 6.1.25 carve). Consumed by owl and any crate parsing structured data.

See the [libs registry](../README.md) for the full catalog and dependency context.
