# darshana

TTY and raw-mode primitives (दर्शन — *viewing, showing*) — termios raw/cooked, ANSI escapes, cursor positioning, alt-screen, SGR colour and `signalfd` delivery, on Linux and AGNOS; not a TUI framework.

- **Repository**: [github.com/MacCracken/darshana](https://github.com/MacCracken/darshana)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Consumers declaring `[deps.darshana]` (local checkouts, 2026-09-28): agora, anuenue, bannermanor, chakshu, cyim, darshini, jalwa, kii.
