# iam

`fastfetch`/`neofetch`-equivalent — system-info display for login MOTD + screenshots (Cyrius-native).

- **Repository**: [github.com/MacCracken/iam](https://github.com/MacCracken/iam)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

A thin presentation layer over the [mihi](mihi.md) probe library — the inverse of `whoami` (whoami says who the user is; iam says what the system is). English-wordplay naming lane.

See the [binaries registry](../binaries.md) for the full catalog and dependency context.
