# ifran

The AGNOS training control plane (عرفان — *gnosis*) — jobs, a signed `.tula` model store, datasets, sweeps, evals and preference data around a training run, never the math (binary).

- **Repository**: [github.com/MacCracken/ifran](https://github.com/MacCracken/ifran)
- **License**: GPL-3.0-only (the Cyrius port, from 2.0.0; the Rust line, removed at 2.2.0, was AGPL-3.0)
- **Status**: Stable — v1.0+
- **Language**: Cyrius

See the [binaries registry](../binaries.md) for the full catalog and dependency context.
