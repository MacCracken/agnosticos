# kashi

AGNOS console-font subsystem (काशि — *shining*) — bitmap console fonts: a freestanding font-data core the agnos kernel includes directly, plus a library face for loading PSF / BDF / PCF fonts at runtime.

- **Repository**: [github.com/MacCracken/kashi](https://github.com/MacCracken/kashi)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius
