# mihi

System-info probe library — CPU / RAM / GPU / kernel / uptime / distro / hostname (Cyrius-native).

- **Repository**: [github.com/MacCracken/mihi](https://github.com/MacCracken/mihi)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

The substrate for [iam](iam.md) (fastfetch-equivalent) and chakshu (system monitor) — anything that needs "tell me about this box." Maori: the formal self-introduction ceremony.

See the [libs registry](README.md) for the full catalog and dependency context.
