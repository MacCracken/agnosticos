# rosnet

Sovereign dense f64 tensor algebra — the BLAS substrate under the whole ML family: storage, BLAS-1, matmul and convolution, each with a hand-derived, finite-difference-gated gradient; a CPU profile plus a mabda-gated GPU profile.

- **Repository**: [github.com/MacCracken/rosnet](https://github.com/MacCracken/rosnet)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Consumers declaring `[deps.rosnet]` (local checkouts, 2026-09-28): akshara, anukūlana, attn11, prajna, rupantara, tarka, tentib.
