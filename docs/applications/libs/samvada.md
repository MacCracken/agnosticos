# samvada

Native D-Bus client (संवाद — *dialogue*) — speaks D-Bus over a raw unix socket in pure Cyrius, including `SCM_RIGHTS` fd passing and the logind session layer; the native path needs no libsystemd.

- **Repository**: [github.com/MacCracken/samvada](https://github.com/MacCracken/samvada)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius
