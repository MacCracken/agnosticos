# shabda

Grapheme-to-phoneme (G2P) engine for AGNOS text-to-speech (Sanskrit *shabda* — word / sound) — text to svara phoneme events via shabdakosh lookup, letter-to-sound rules and prosody.

- **Language**: Cyrius
