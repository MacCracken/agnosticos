# tarang

AI-native media framework (Sanskrit *tarang* — wave) — containers, audio/video decode and encode, and AI content analysis; built to replace ffmpeg.

- **Repository**: [github.com/MacCracken/tarang](https://github.com/MacCracken/tarang)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Rust (Cyrius port deferred)
