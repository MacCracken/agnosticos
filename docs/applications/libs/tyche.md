# tyche

Sovereign deterministic statistical PRNG (τύχη — the Greek deity of fortune and chance) — xorshift64 with a splitmix64 seed finalizer and Marsaglia-polar normals: reproducible randomness for the ML family, and **not** a CSPRNG (crypto lives in sigil).

- **Repository**: [github.com/MacCracken/tyche](https://github.com/MacCracken/tyche)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius
