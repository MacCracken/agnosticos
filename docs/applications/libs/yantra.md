# yantra

Sovereign UI automation library — browser + mobile (Cyrius-native).

- **Repository**: [github.com/MacCracken/yantra](https://github.com/MacCracken/yantra)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+ (folded into the Cyrius stdlib at 6.2.26)
- **Language**: Cyrius

`.tcyr` files include `lib/yantra.cyr` and drive Chromium / Firefox / WebKit / Android / iOS; `cyrius test` stays the runner — it's a library, not a framework. As of Cyrius 6.2.26 the surface is vendored into the stdlib. See the article *Draw the Line After*.

See the [libs registry](README.md) for the full catalog and dependency context.
